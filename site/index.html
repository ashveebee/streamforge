Features

Everything at a glance

One place to see your server, instead of six browser tabs.

Now Playing, live

Every active stream with artwork, progress, user and device, plus direct play or transcode details. Pause, message or stop a stream when you need to.

Health monitoring

Each service is checked every 30 seconds for status, response time, uptime and the problems it reports about itself, with an alert when one goes down.

Downloads and calendar

Sonarr and Radarr queues with live throughput and one-click blocklist, re-search or remove. See what's missing and what's airing next, across as many instances as you run.

Requests

Seerr requests waiting for approval and recently fulfilled, with who asked and when. Approve or decline right from the dashboard.

Storage

Capacity, usage, temperatures and health for every drive, plus a forecast of when each volume will fill up and an alert before it does.

Set up from the UI

Add each service's address and API key in Settings, test the connection and save. Switch off what you don't use. Changes apply instantly, with no config files or restarts.

Automation and insight

It fixes the usual problems for you

Stuck imports, dead downloads and full disks get handled, and you hear about anything that can't be.

Auto-import

Downloads Sonarr or Radarr couldn't match get matched from grab history, the release name and your library, then imported. Conflicting signals are never guessed at, and Preview shows what it would do first.

Stalled download cleanup

Downloads that stop making progress, or that fail, are removed, blocklisted and searched for again, so the queue keeps moving without you.

Notifications

Discord, ntfy, Pushover, webhooks or push to your phone. Pick the events for each: outages, full disks, failed imports and new requests.

Playback stats

Plays and watch time per day, direct play vs transcode, top viewers, titles and clients, and a heatmap of when people watch.

Library health

Series with missing episodes, files that could be upgraded, downloads Jellyfin never picked up, and items nothing is managing.

Install it like an app

Add StreamForge to your phone's home screen or your desktop. It opens like any other app, and push notifications reach your phone.

Now Playing

See who's watching what, right now

A cinematic view of every stream, updated every few seconds, with the progress bar moving in between.

  • Resolution, HDR, codecs and bitrate
  • Transcode reasons and hardware acceleration
  • User, device and client for each session
  • Pause, message or stop a stream
System Status

Know something's wrong before anyone else does

Response-time history, uptime and the warnings each service reports, plus your host's CPU, memory, network and disks.

  • Healthy, degraded and offline at a glance
  • Issues straight from Sonarr, Radarr and Prowlarr
  • Host metrics and download throughput
  • Storage forecast and stalled download cleanup
Settings

Connect a service in seconds

Paste an address and API key, click Test connection, then Save. Keys stay on your server, and the browser only ever sees the last four characters.

  • Changes apply immediately, with no restart
  • Environment variables still work as a fallback
  • Add a second Sonarr or Radarr, such as a 4K library
  • Switch off services you don't use

Screenshots use the built-in demo data. All titles, people and artwork are fictional.

Install

Up and running in a minute

One container, multi-arch images for amd64 and arm64. All you need is Docker and a Jellyfin server.

docker-compose.yml
services:
  streamforge:
    image: ghcr.io/ashveebee/streamforge:latest
    container_name: streamforge
    ports:
      - "4000:4000"
    volumes:
      - streamforge-data:/data   # settings database
    restart: unless-stopped

volumes:
  streamforge-data:

Start the container

Save the file above and run docker compose up -d, or use the one-line docker run from the README.

Connect Jellyfin

Open http://your-server:4000, enter your Jellyfin address and sign in with a Jellyfin administrator account.

Add your services

In Settings, add the address and API key for Sonarr, Radarr, Prowlarr, Seerr and Infinidisk. Skip any you don't use.

Full guide, Docker networking tips, backups and troubleshooting are in the installation docs. Want to look around first? Clone the repo and run npm run demo.

Security

Your keys never leave the server

Server-side credentials

API keys and Jellyfin tokens stay on the server. The browser only gets an opaque, HttpOnly session cookie.

Jellyfin sign-in

Sign in with your existing Jellyfin account. Only administrators get in by default; you choose which pages the rest of the household sees.

Hardened by default

CSRF protection, rate-limited login, a strict content security policy and artwork proxied through validated routes.

Signed images

Every release image ships with an SBOM and build provenance you can verify with gh attestation verify.
